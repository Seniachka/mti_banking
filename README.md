# ООП-Банк
Учебный проект для на python и PyQT6, симулирующий работу простейшего онлайн-банка.

Запуск на:

python main.py

Чтоб все гуд работало, надо установить пакет python-pyqt6(либо сделать это в виртуальном окружении и запустить там же, но это умом будет)
